1 Цель работы

Освоить методы структурного тестирования программного обеспечения, научиться применять критерии покрытия C0 (операторы), C1 (ветви/решения) и C2 (пути) для разработки тестовых наборов. В ходе работы студенты строят управляющий граф программы, определяют минимальное количество тестов для достижения 100% покрытия по каждому критерию, реализуют тесты с использованием фреймворка Google Test.

2 Задание 1. Построение УГП

Для каждой функции из Приложения 1 (исходный код) постройте управляющий граф программы.

  • Каждая вершина графа должна соответствовать оператору или условию.
  • Рёбра показывают переходы управления.
  • Рекомендуется нумеровать вершины согласно комментариям в коде (например, // условие 1).
3 Задание 2. Разработка тестов

На основе анализа кода разработайте минимальный набор тестовых случаев, который обеспечивает:

  • 100% покрытие операторов (C0)
  • 100% покрытие ветвей (C1)
  • 100% покрытие путей (C2)

Для каждого теста укажите:

  • Входные данные (аргументы)
  • Ожидаемый результат
  • Какие пути/ветви/операторы покрываются (можно в виде таблицы)
4 Задание 3. Реализация тестов (Google Test)

Напишите тесты на C++ с использованием фреймворка Google Test.

  • Используйте макросы EXPECT_EQ, EXPECT_DOUBLE_EQ, EXPECT_TRUE/EXPECT_FALSE.
  • Убедитесь, что тесты для функций с ошибками падают, затем исправьте ошибки и проверьте, что все тесты проходят.
  • В отчёте приведите листинг всех тестов с комментариями о покрытии.
5 Распределение заданий

Каждый студент выполняет две функции:

  • Одномерная – номер (N-1) % 8 + 1, где N – порядковый номер в списке группы.
  • Двумерная – номер (N-1) % 5 + 1.
Примеры:
Студент №1 → одномерная №1, двумерная №1.
Студент №6 → одномерная №6, двумерная №1.
Студент №10 → одномерная №2, двумерная №5.
Студент №17 → одномерная №1, двумерная №2.

Нумерация функций соответствует порядку в списках Задания 4.

6 Задание 4. Самостоятельная работа

В соответствии с вашим вариантом (определяется преподавателем) реализуйте две функции из списков ниже. Для каждой:

  • Постройте УГП
  • Разработайте тесты для C0, C1, C2
  • Напишите тесты на Google Test

Функция 1 – одномерные массивы (корзина товаров)

1. Необходимо реализовать функцию double productOddIndices(const std::vector<double>& prices) для того, чтобы вычислять произведение цен товаров, стоящих на нечётных индексах корзины. Если корзина пуста или нет нечётных индексов, функция должна возвращать 1.0.
2. Необходимо реализовать функцию void rotatePricesRight(std::vector<double>& prices, int shift) для того, чтобы выполнять циклический сдвиг цен товаров в корзине вправо на заданное число позиций. При пустой корзине или shift <= 0 массив не изменяется.
3. Необходимо реализовать функцию double productByIndices(const std::vector<double>& values, const std::vector<int>& indices) для того, чтобы вычислять произведение цен товаров из корзины values, позиции которых заданы в массиве indices. Некорректные индексы игнорируются, при пустом массиве indices возвращается 1.0.
4. Необходимо реализовать функцию void reversePrices(std::vector<double>& prices) для того, чтобы переставлять цены товаров в корзине в обратном порядке. При пустой корзине ничего не делать.
5. Необходимо реализовать функцию double maxPriceOddValueOddIndex(const std::vector<int>& prices) для того, чтобы находить максимальную цену среди товаров, у которых значение цены нечётное (целая часть) и индекс тоже нечётный. Если таких товаров нет, возвращать 0.0.
6. Необходимо реализовать функцию double productEvenIndices(const std::vector<double>& prices) для того, чтобы вычислять произведение цен товаров, стоящих на чётных индексах корзины. Если корзина пуста, возвращать 1.0.
7. Необходимо реализовать функцию void rotatePrices(std::vector<double>& prices, int shift, int direction) для того, чтобы выполнять циклический сдвиг цен товаров в корзине на shift позиций в указанном направлении (direction = 0 – вправо, direction = 1 – влево). При пустой корзине или shift <= 0 массив не изменяется.
8. Необходимо реализовать функцию double maxPriceEvenValueEvenIndex(const std::vector<int>& prices) для того, чтобы находить максимальную цену среди товаров, у которых значение цены чётное и индекс тоже чётный. Если таких товаров нет, возвращать 0.0.

Функция 2 – двумерные массивы (матрица цен)

1. Необходимо реализовать функцию int sumOddAboveMainDiagonal(const std::vector<std::vector<int>>& A) для того, чтобы вычислять сумму нечётных элементов двумерного массива (матрицы цен), расположенных выше главной диагонали (индекс строки < индекс столбца). Если таких элементов нет, возвращать 0.
2. Необходимо реализовать функцию int sumOddBelowMainDiagonal(const std::vector<std::vector<int>>& A) для того, чтобы вычислять сумму нечётных элементов двумерного массива (матрицы цен), расположенных ниже главной диагонали (индекс строки > индекс столбца). Если таких элементов нет, возвращать 0.
3. Необходимо реализовать функцию int sumEvenAboveSecondaryDiagonal(const std::vector<std::vector<int>>& A) для того, чтобы вычислять сумму чётных элементов двумерного массива (матрицы цен), расположенных выше побочной диагонали (индекс строки + индекс столбца < размерность массива - 1). Если таких элементов нет, возвращать 0.
4. Необходимо реализовать функцию double minOnAndAboveSecondaryDiagonal(const std::vector<std::vector<double>>& A) для того, чтобы находить минимальное значение среди элементов двумерного массива (матрицы цен), расположенных на побочной диагонали и выше неё (индекс строки + индекс столбца <= размерность массива - 1). Если массив пустой, возвращать 0.0.
5. Необходимо реализовать функцию double productOddIndexSum(const std::vector<std::vector<double>>& A) для того, чтобы вычислять произведение элементов двумерного массива (матрицы цен), у которых сумма индексов (строка + столбец) является нечётной. Если таких элементов нет, возвращать 1.0.

order_calc.cpp

// 1. Расчёт скидки
// Описание: возвращает сумму со скидкой в зависимости от стоимости заказа и статуса клиента.
// - Если total < 0, возвращает -1.0 (ошибка).
// - Если total >= 10000: скидка 20% для премиум-клиентов, 15% для обычных.
// - Если total >= 5000: скидка 10% для премиум-клиентов, 5% для обычных.
// - В остальных случаях скидка 0%.
double applyDiscount(double total, bool isPremium) {
  if (total < 0)
    return -1.0;
  if (total >= 10000) {
    if (isPremium) {
      return total * 0.80;
    } else {
      return total * 0.85;
    }
  } else if (total >= 5000) {
    if (isPremium) {
      return total * 0.90;
    } else {
      return total * 0.95;
    }
  }
  return total;
}

// 2. Расчёт стоимости доставки
// Описание: возвращает стоимость доставки в зависимости от суммы заказа.
// - Если total < 0, возвращает -1.0 (ошибка).
// - Если total >= 5000, доставка бесплатная (0.0).
// - Иначе доставка стоит 300.0.
double calcShipping(double total) {
  if (total < 0)
    return -1.0;
  if (total <= 5000)
    return 0.0;
  return 300.0;
}

// 3. Итоговая цена
// Описание: вычисляет финальную стоимость заказа с учётом скидки и доставки.
// - Если любой аргумент отрицательный, возвращает -1.0 (ошибка).
// - Если итоговая цена получается отрицательной, она обнуляется (0.0).
// - Результат округляется до двух знаков после запятой.
double finalPrice(double total, double discount, double shipping) {
  if (total < 0 || discount < 0 || shipping < 0)
    return -1.0;
  double result = total - discount + shipping;
  if (result < 0)
    result = 0.0;
  return std::round(result * 100) / 100;
}

// 4. Подсчёт количества дорогих товаров в корзине
// Описание: возвращает количество товаров, цена которых превышает заданный порог.
// - Если вектор пустой, возвращает 0.
// - В противном случае подсчитывает количество элементов > threshold.
int countExpensiveItems(const std::vector<double>& prices, double threshold) {
  int count = 0;
  for (size_t i = 0; i < prices.size(); ++i) {
    if (prices[i] > threshold) {
      count++;
    }
  }
  return count;
}
